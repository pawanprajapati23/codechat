# 💕 CodeChat Love - Full Stack Real-Time Chat

A production-ready, love-themed real-time chat application with Node.js backend and React frontend.

## 🚀 Quick Start

### Local Development
```bash
# Terminal 1: Backend
cd backend && npm install && npm run dev

# Terminal 2: Frontend  
cd frontend && npm install && npm run dev
```

Open: http://localhost:5173

## 🎯 Features

- ✅ Real-time messaging (Socket.IO)
- ✅ Room management
- ✅ User presence & typing indicators
- ✅ Message reactions (8 emojis)
- ✅ Emoji picker (100+ emojis)
- ✅ Image & media sharing
- ✅ Love-themed UI with animations
- ✅ Sound & browser notifications
- ✅ Fully responsive
- ✅ Production ready

## 📊 Tech Stack

**Backend:** Node.js, Express, Socket.IO  
**Frontend:** React, Vite, Socket.IO Client  
**Deploy:** Render (Backend) + Vercel (Frontend)
