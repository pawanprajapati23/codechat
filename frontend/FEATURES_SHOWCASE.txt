## 🎯 INTERVIEW TALKING POINTS

### Feature 1: Emoji Picker
**Q: How did you implement the emoji picker?**
> "I used emoji-picker-react library. The tricky part was handling click-outside to close the picker. I used useRef to track the picker element and useEffect to listen for clicks, then check if the click was outside."

### Feature 2: Code Highlighting
**Q: How does code syntax highlighting work?**
> "I used regex to detect triple-backtick code blocks with optional language identifier. Then I parse the message into parts (text vs code), and render code parts using react-syntax-highlighter with Prism themes. There's also a copy button using the clipboard API."

### Feature 3: Reactions
**Q: How do you manage message reactions?**
> "Each message object has a reactions property storing emoji counts. When someone reacts, I map through messages, find the matching one by timestamp and sender, update its reactions object, and set the new state. I also emit a Socket event so other users see it in real-time."

### Feature 4: Loading Skeletons
**Q: Why skeletons instead of a spinner?**
> "Skeleton screens are proven to reduce perceived loading time. They show the structure of the UI while content loads, so users know what to expect. It's a pattern used by Facebook, LinkedIn, and YouTube."
